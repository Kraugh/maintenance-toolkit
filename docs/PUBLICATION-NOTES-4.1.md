# Maintenance Toolkit 4.1.0 — IT/EN release copy

## Italiano

MT 4.1.0 introduce V per aggiornare MT standalone con conferma, G per gestione/opt-in protetto e P per creare, ispezionare, modificare o rimuovere la pianificazione SYSTEM. Manutenzione completa consigliata, analisi o sola rilevazione aggiornamenti; destinazione JSON opzionale. Policy macchina prioritaria, gestione sconosciuta in sola rilevazione; GPO mantiene installazione e task. Nessun task updater permanente o riavvio automatico. Primo upgrade dalla 4.0.6 manuale.

H seleziona italiano, inglese, francese, spagnolo, tedesco, cinese semplificato e giapponese. Le cinque nuove traduzioni sono parziali con fallback inglese per le diagnostiche storiche. Documentazione pubblica soltanto IT/EN.

117 regressioni; Foundation zero errori/avvisi. Pilota privato Windows 11/PowerShell 5.1 per MSI/ZIP, recupero, ripresa unica, SYSTEM e UNC locale; Windows 10 escluso per deroga. Non certifica share aziendali o installazione Winget selettiva reale. Verifiche sui pacchetti finali distinte dal pilota; sito da caricare separatamente dopo GitHub.

## English

MT 4.1.0 adds V for confirmed standalone MT updates, G for protected management/opt-in, and P to create, inspect, modify or remove SYSTEM schedules. Full maintenance is recommended, with analysis or update detection alternatives and optional JSON destination. Machine policy takes precedence; unknown management detects only; GPO retains installation/task ownership. No additional permanent updater task or automatic restart. The first upgrade from 4.0.6 is manual.

H selects Italian, English, French, Spanish, German, Simplified Chinese or Japanese. The five additional translations are partial, with English fallback for historical diagnostics. Public documentation is IT/EN only.

117 regressions; Foundation zero errors/warnings. Private Windows 11/PowerShell 5.1 MSI/ZIP, recovery, single-resume, SYSTEM/loopback UNC pilot; Windows 10 testing waived. No corporate-share or live selective Winget installation guarantee. Final-package verification is separate from the pilot; website upload follows GitHub separately.
