MAINTENANCE TOOLKIT 4.0
=======================

Strumento gratuito e open source per la manutenzione, la diagnostica
e il reporting tecnico dei sistemi Microsoft Windows.

Release stabile corrente:
    3.7.2

Pre-release corrente:
    4.0.0-rc.1

Autore:
    Luca Miselli
    https://www.kraugh.it

Repository ufficiale:
    https://github.com/Kraugh/maintenance-toolkit

Licenza:
    MIT License
    Consultare il file LICENSE.

MT4 integra i moduli di manutenzione della serie 3.7.x con un core
bilingue, Network Diagnostics, Rules Engine, diagnostica VPN e report
tecnici di rete.

Sviluppato con l'indispensabile aiuto
di una Rubber Duck molto paziente.

Se questo Toolkit ti ha fatto risparmiare mezz'ora di lavoro,
allora ha raggiunto il suo scopo.
